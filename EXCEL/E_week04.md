## 05-1. 엑셀 데이터 관리의 기본 규칙
> **데이터 관리를 할 때 주의해야 할 점에 대해 설명해주세요.**

1. 줄바꿈/빈셀 사용 자제
- 줄바꿈 사용: 수식 사용 문제
- 빈셀 사용: 범위 선택 문제,빈셀 참조(=E6)시 0 반환

2. 집계데이터/원본데이터는 구분하여 관리
- 함께 관리시 
    ➀ 피벗테이블 사용의 어려움
    ➁ 함수사용의 어려움

3. 머리글은 한 줄로 입력
- 범위 여러개 선택 시 문제 (sum 사용 등)
- 표, 피벗 테이블 활용의 문제 (추가 수정 필요)
