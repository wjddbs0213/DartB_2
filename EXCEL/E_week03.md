## 04-5. 엑셀은 보안 측면에서 완벽한 프로그램이 아니다
> **데이터 유효성 검사로 입력할 데이터 제한하기(179 ~183p)를 진행 후 인증사진을 첨부해주세요.**
![오류](../image/27.png)
- 데이터 유효성 검사 - **허용: 목록** - 원본: **=제품정보!$A$2:$A$9** 입력
    - 목록에 없는 항목은 걸러짐
![오류](../image/28.png)

- 데이터 유효성 검사 - **허용:정수** - 최댓/최솟값 설정 - 오류메시지 입력
![오류](../image/29.png)
최댓/최솟값을 넘어선 정수가 입력될 시에 지정한 오류메시지가 뜸


### 📌 데이터 유효성 검사의 제한 대상[cite: 6]

| 제한 대상 | 설명 |
| :--- | :--- |
| **정수** | 최솟값과 최댓값을 지정하여 정수만 입력할 수 있습니다. |
| **소수점** | 최솟값과 최댓값을 지정하여 소수만 입력할 수 있습니다. |
| **목록** | 원본으로 설정한 목록만 입력할 수 있습니다. (특정 범위 지정 또는 쉼표(,)로 직접 입력 가능. 예: `사과,배,포도`) |
| **날짜** | 시작 날짜와 끝 날짜를 지정하여 해당 범위의 날짜만 입력할 수 있습니다. |
| **시간** | 시작 시간과 종료 시간을 지정하여 해당 범위의 시간만 입력할 수 있습니다. |
| **텍스트 길이** | 최솟값과 최댓값을 지정하여 정해진 길이의 텍스트를 입력할 수 있습니다. |
| **사용자 지정** | 수식을 입력하여 조건에 만족하는 값만 입력할 수 있습니다.<br>• 예) '가'로 시작하는 텍스트만 허용: `=LEFT(셀 주소, 1)="가"` |


> **시트 내용을 수정하지 못하도록 보호하기(186 ~190p)를 진행 후 인증사진을 첨부해주세요.**

### 🔒 시트 보호 중 특정 기능 사용 허용하기[cite: 7]

* **개요**: 셀 편집은 제한하되 자동 필터, 개체 편집 등 필요 기능만 선택적으로 허용하는 설정임[cite: 7]
* **설정 방법**: `시트 보호` 대화상자 → 암호 입력 → `허용할 내용` 목록 체크 → `[확인]`[cite: 7]

### 📄 머리글이나 바닥글 활용하기[cite: 8]

* **기능 개요**: 각각 3개 영역으로 구성되며, 입력 시 모든 페이지에 반복 인쇄됨[cite: 8]
* **설정 방법**: `페이지 레이아웃 보기` 모드 → 머리글/바닥글 영역 클릭 → 텍스트 입력[cite: 8]
* **자동 요소 활용**:
  * `[머리글/바닥글 요소]` 그룹 사용 시 편리함[cite: 8]
  * `[현재 날짜]` 클릭 시 `&[날짜]` 입력, `[현재 시간]` 클릭 시 `&[시간]` 입력됨[cite: 8]
  * 인쇄 시 현재 날짜 및 시간이 자동으로 표시됨[cite: 8]
* **주의 사항**: 프린터 사양에 따라 여백이 좁으면 바닥글이 잘려 인쇄될 수 있음[cite: 8]
